# 페어리테일 3부작 한국어 패치

라이어소프트의 **페어리테일 레퀴엠·앙코르·심포니** 한국어 패치와 두 종류의 통합판 제작기를 공개합니다. 이용하려는 작품의 지원 설치본이 필요합니다. 원본 게임 전체와 개인 세이브는 포함하지 않습니다.

## 다운로드

**[2026.11.26 미리보기 릴리스](https://github.com/sirecoymarsh/fairytale-trilogy-korean-patch/releases/tag/patches-preview-2026.11.26)**에서 아래 패키지를 받으세요. `Code → Download ZIP`은 소스 자료입니다.

| 패키지 | 용도 | 필요한 설치본 |
|---|---|---|
| `Fairytale_Requiem_Korean_Patch_…zip` | 레퀴엠 개별 한국어판 만들기 | 레퀴엠 |
| `Fairytale_Encore_Korean_Patch_…zip` | 앙코르 개별 한국어판 만들기 | 앙코르 |
| `Fairytale_Symphony_Korean_Patch_…zip` | 심포니 개별 한국어판 만들기 | 심포니 |
| `Fairytale_Collection_Builder_…zip` | 공통 메뉴에서 작품별 게임을 실행하는 브릿지 | 1~3개 작품 |
| `Fairytale_Story_Collection_Builder_…zip` | 한 게임 엔진에서 세 작품의 시나리오를 실행하는 이야기 모음 | 세 작품 모두 |

릴리스에는 레퀴엠·앙코르의 한국어 오프닝 홍보 영상도 첨부했습니다. 각각 **45.34 MB / 45.14 MB**로 50 MB 미만이며, 게임용 영상과 별개인 게시판 첨부용 MP4입니다. 파일 확인용 `SHA256SUMS.txt`와 `verification-20261126.json`을 함께 제공합니다.

## 설치와 사용

1. 원하는 ZIP을 모두 풉니다.
2. 패치 적용 또는 제작기 EXE를 실행하고 작품별 설치 폴더를 고릅니다.
3. 필요한 작품만 **세이브 가져오기**를 선택합니다. 기본값은 새로 시작하기입니다.
4. 원본과 겹치지 않는 새 빈 출력 폴더를 지정해 만듭니다.
5. 완성된 폴더의 게임 EXE를 실행합니다. 이동할 때는 폴더 전체를 함께 옮깁니다.

지원하는 일본어 원본 또는 기존 한국어판의 파일 크기와 SHA-256을 확인해 별도 사본을 구성합니다. 다른 판본이나 알 수 없는 파일은 중단하며 원본 게임과 세이브를 덮어쓰지 않습니다. Python은 동봉되어 있습니다.

## 두 통합판의 차이

**브릿지**는 기존 세 게임을 공통 성 메인과 감상실로 연결합니다. 일부 작품만 있어도 만들 수 있고, 없는 작품은 흑백 문과 `미설치` 표시로 남습니다. 작품별 실행 파일과 저장 폴더를 유지합니다.

**이야기 모음**은 같은 성 메인을 사용하면서, 하나의 게임 엔진이 세 작품의 시나리오와 자료를 읽습니다. 세 설치본이 모두 필요하며, 진행·설정·저장은 작품별로 구분합니다. 원작 시나리오 파일 428개를 보존하고 공통 엔진에서 작품을 전환합니다.

두 제작기는 CG·음악·영상 감상실, 회상, 앙코르 에피소드 선택과 CG 마우스 휠 확대를 제공합니다. 설치 경로는 사용자가 직접 선택하며, 완성 후에는 사본 내부의 상대 경로를 사용합니다.

## 검증 범위와 제한

**전체 작동 검증이 끝난 정식판이 아닌 미리보기입니다.** 기본 작동 검증과 기존 유효한 결과를 아래와 같이 구분해 공개합니다.

| 대상 | 확인한 범위 |
|---|---|
| 공통 한국어 패치 | 원본→한국어 파일 84개 해시 검증, 세 작품 첫 장면·복귀 기록 재사용 |
| 새 개별 설치기 | 심포니 실제 GUI 설치, 20개 출력 파일 검증, 한국어 첫 장면과 정상 종료; 원본/제작기 내부 출력 거부 |
| 브릿지 | 세 작품 원본부터 제작, 다른 드라이브 경로에서 시작·복귀, 선택 세이브 복사, 설치 조합 8가지·감상실 32개 경로 |
| 이야기 모음 | 한 게임 프로세스에서 세 작품 첫 장면·복귀, 앙코르 저장·불러오기, 설정·취소 후 메인 복귀, 선택 세이브, 이동 후 실행·정상 종료 |
| 영상 | 홍보 영상 2편·감상실 MP4 7편 전체 디코드; 감상실 재생 및 끝 부근 탐색 후 자연 종료 |

**남은 범위:** 전체 분기·엔딩 완주, 모든 게임 내 영상의 연속 전체 재생, 새로운 PC에서의 전체 제작·실행, 영상 프레임 드롭·지터 측정. 이야기 모음은 원작 시나리오를 보존하지만 모든 시나리오를 플레이해 확인한 것은 아닙니다.

Windows 10/11 64비트와 .NET Framework 4.8 이상이 필요하며, 두 통합판은 WebView2도 필요합니다. 새 Windows Sandbox에서는 Smart App Control이 서명되지 않은 xdelta3 실행을 차단했습니다. 제작기와 새 EXE/DLL은 코드 서명이 없는 미리보기이며 해당 정책 환경은 현재 호환성 제한입니다. 보안 설정 변경이나 우회를 요구하지 않습니다.
