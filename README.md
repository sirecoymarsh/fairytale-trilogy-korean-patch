# 페어리테일 레퀴엠·앙코르·심포니(라이어소프트) 한국어 패치 작업물

라이어소프트의 「페어리테일 레퀴엠」, 후속작 「페어리테일 앙코르」·「페어리테일 심포니」를 한국어로 옮긴 작업물 보관 저장소다.
패치 코드·도구·번역 텍스트와, 게임이 실제로 읽는 한국어화 그림(원본과 달라진 항목만)을 담는다.

원본 게임 파일, 추출한 원문 데이터, 음성·영상, 실행 파일과 빌드 결과는 넣지 않았다.
패치를 다시 만들려면 원본 게임이 따로 필요하다.

## 추가·변경 사항

원판(일본어 원본 디스크 설치본) 대비 이 패치가 바꾸거나 더한 것을 작품별로 정리했다.
괄호 안은 근거가 된 파일·커밋이다. 확실하지 않은 것은 「(추정)」으로 표시했다.
이 저장소에는 2026-11-25에 작업 폴더를 한꺼번에 옮겨 담았으므로, 커밋 기록(4개)보다 폴더 안의 기록 파일(`progress.json`, `project.json`, 검수 보고서, 설치 기록)이 실제 작업 순서를 더 잘 보여 준다.

### 공통

- **번역 원문**: 세 작품 모두 일본어 원본 디스크판이다(영문판 경유 없음). 대본은 CP932(Shift-JIS)로 된 `scr.xfl` 안의 `.gsc` 파일이며, 한국어는 CP949로 넣었다 (`requiem/language_contract.json`, `requiem/adapter/contract.json`).
- **보존 규칙**: 캐럿 제어 코드(`^n ^m ^d2 ^d3 ^s2`)의 종류·개수·순서, 루비 `|표기[읽기]` 구조, 명령 구간과 번역하지 않는 문자열 칸은 원본과 바이트 단위로 같게 두었다. opcode `0x79`의 조회 키는 번역하지 않고, opcode `0x0F` 문자열은 화면 표시가 확인될 때까지 제외했다 (`requiem/glossary/style_guide.md`).
- **화면 폭**: 대사는 한 칸에 최대 3줄, 실측 폭 1000픽셀 안에 들어가도록 줄을 나눴다 (`requiem/adapter/scenario_layout.py`).
- **표기 통일(2026-11 검수)**: 세 작품 대본에서 「聖書」를 「성경」→「성서」로 통일했다(레퀴엠 16칸, 앙코르 48칸, 심포니 49칸). 레퀴엠은 「ゴーテル」를 「고델」→「고텔」(33칸), 「おばあさま」를 「할머님」(24칸)으로 맞추고 띄어쓰기 1칸을 고쳤다 (`review-2026-11/terms_edits_final.json`, `review-2026-11/build_report.json`, `review-2026-11/install_log.json`).
- **말투 통일(2026-11 검수)**: 「원문이 반말이면 반말, です・ます면 존댓말」 규칙으로 인물별 말투를 조사하고(`review-2026-11/notes/말투조사_20261123.md`), 레퀴엠 807칸·심포니 41칸, 모두 848칸의 말끝·1인칭·2인칭을 고쳐 넣었다. 레퀴엠 앨리스 488칸, 라푼젤 104칸, 오데트 98칸, 게르다 40칸, 의사 38칸, 검은 쪽(black) 23칸, 오딜 8칸, 팅크 7칸, 오자 1칸, 심포니 앨리스 41칸이다. 의사의 「자네」는 「너」로, 하게체는 다정한 해체로 바꿨다 (`review-2026-11/voice_edits_v3.json`, `review-2026-11/install_log_v3.json`).
  - 기계적으로 「요」를 떼며 생긴 혼잣말투·명령조·깨진 활용은 제미나이 「말맛」 점검(848줄 중 48줄 수정)과 Claude 추가 손질 10칸으로 다시 다듬었다. 제미나이 안 중 2건(R1135-56, R1416-99)은 받지 않았다 (`review-2026-11/mallmat/답/요약.md`, `review-2026-11/notes/말투고침_v3_말맛반영_20261123.md`).
  - 앙코르는 말투 조사에서 고칠 것이 없다고 판정해 말투 고침을 넣지 않았다.
- **한국어화 그림**: 한국어판 그림 압축 파일(`.xfl`)을 원본과 비교해 달라진 항목만 게임 형식(`.wcg`/`.lwg`) 그대로 `assets-ko/`에 담았다. 레퀴엠 1,370개, 앙코르 310개, 심포니 329개다. 2MB가 넘는 고해상도 CG는 저장소에 올리지 않았다 (`assets-ko/README.md`, `52526c5`, `d90e196`, `a9095af`).
- **세 작품이 같이 쓰는 그림**: 시스템 화면 레이어 112종, 서재 그림 58종, 지도 그림 68종 등은 세 작품에서 원본이 같아, 레퀴엠에서 만든 한국어 그림을 후속작에 다시 썼다 (`encore-symphony/작업량.md`).

- **화면·그래픽**: 원본과 같은 1280×720 화면이다. 해상도·와이드 확장은 없다. 앙코르·심포니 실행 파일에서는 글꼴 설정을 바꾸지 않았고, 설정 화면의 글꼴 이름은 원래의 「ＭＳ ゴシック」로 보인다. 한글이 어떤 경로로 표시되는지는 기록이 없어 확인이 필요하다 (`progress.json`의 `content_options.default_font_display`) (추정).

### 페어리테일 통합판(새로 만든 실행기)

세 작품을 한 화면에서 고르는 「페어리테일 통합판.exe」를 새로 만들었다. WPF와 WebView2로 만든 창이고, 원판에는 없는 프로그램이다 (`encore-symphony/collection/Castle.cs`, `castle.js`, `index.html`, `progress.json`의 `collection_release`).

- **공통 메인 화면**: 시작 / 계속 / 감상 / 설정 / 영상 / 조작 / 종료. 시작·계속·설정은 「작품 선택」 화면(레퀴엠·앙코르·심포니 세 문)으로 이어진다. 메인과 작품 선택 화면은 따로 디자인했다 (`design/collection-main-menu/`).
- **작품 바로 실행**: 고른 작품의 `scr.xfl` 중 `0000.gsc` 하나만 바꾼 진입용 압축을 써서 첫 장면, 저장 목록, 환경 설정, 회상, 앙코르 에피소드 선택, 심포니 원작 크레딧으로 바로 들어간다. 게임 창을 닫거나 게임에서 타이틀로 돌아오면 통합 화면으로 돌아온다. 원작 확인 대화상자는 자동으로 「예」를 누른다 (`collection/boot.py`, `entries.py`, `Castle.cs`).
- **통합 감상실**: 세 작품의 CG 99묶음·359장, 음악 11곡, 영상 7편, 회상을 탭(CG·음악·영상·회상)과 작품별 보기(전체/레퀴엠/앙코르/심포니)로 본다. 각 작품에서 연 기록만 보이고, 「모든 콘텐츠 해방」을 켜면 모두 보인다. CG는 휠로 확대, 끌어서 이동, 두 번 눌러 화면 맞춤, 좌우 화살표로 차분을 넘긴다 (`collection/castle.js`, `album.py`, `release-check.json`).
- **통합 환경 설정**: 감상실 음량(음악·영상에 적용, 브라우저 저장소에 기억), 전체 화면 전환, 작품별 환경 설정으로 가기.
- **저장**: 세 작품의 저장 파일(`FRsave`, `FAsave`, `FSsave`)은 따로 유지한다. 통합판은 이미 열려 있으면 하나 더 열지 않는다.
- **감상실 음악 수리**: 게임의 Vorbis 음원에 섞여 있던 빈 패딩 스트림(serial 0xffffffff)의 빈 페이지 19,426개를 걷어 내 끝까지 이어 재생되게 했다. 코덱 변환은 하지 않았고 원래 페이지·샘플 수는 그대로다 (`collection/runtime-verification.json`의 `gallery_music_repair`).

### 설치·제거 방식

- 설치 도구는 원본 실행 파일·압축 파일의 SHA-256을 먼저 확인하고, 맞을 때만 고친 파일을 만든다 (`build_korean_output_exe.py`, `native_ui.py`, `qol/build_options.py`).
- 고친 파일을 옆에 임시 이름으로 다 만들고 해시를 확인한 뒤 바꿔 넣는다. 중간에 실패하면 이미 바꾼 파일을 백업본으로 되돌린다. 설치 전 원본은 따로 보관한다 (`qol/install_options.py`, `review-2026-11/install_log*.json`의 백업 기록).
- 대본(`scr.xfl`)은 파일마다 「바꾸지 않고 다시 묶었을 때 원본과 바이트가 같은지」를 먼저 확인한 다음 번역을 넣는다 (`requiem/adapter/build_gsc_from_translation_map_v2.py`, `requiem/adapter/contract.json`).
- 지원 판본: 일본어 원본 디스크 설치본. 레퀴엠 실행 파일은 codeX RScript 1.11.0.3, 대본 302개다. 앙코르·심포니는 2015·2016년 11월 codeX 빌드다 (`requiem/adapter/contract.json`, `qol/content_options.cpp`). 스팀·DL판 지원 여부는 기록이 없다.
- 배포용 설치 프로그램이나 차분 파일(xdelta 등)은 이 저장소에 없다. 지금은 작업용 스크립트로 직접 설치하는 방식이다.

### 알려진 문제

- 레퀴엠: 프로젝트 기록상 `release_ready`가 false다. 8월 시점에는 시나리오 본문을 화면에서 확인하지 않았다고 적혀 있다. 11월 통합판 확인에서 세 작품의 첫 한국어 대사까지는 확인했다 (`requiem/project.json`, `collection/runtime-verification.json`).

- 영상: Windows Media Player 레거시 구성 요소가 없는 PC에서는 통합판 영상이 오류 0x88980507로 재생되지 않았다 (`progress.json`의 `collection_release.portability_check`).
