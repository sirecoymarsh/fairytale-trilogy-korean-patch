# 페어리테일 3부작 한국어화

라이어소프트의 **페어리테일 레퀴엠·앙코르·심포니** 한국어화 소스와 작업 자료를 공개합니다.

대사와 화면 문구, 한국어로 수정한 그림, 영상 제작 도구, 세 작품을 연결하는 통합 실행기 소스가 포함되어 있습니다. 게임을 이용하려면 해당 작품의 원본이 필요합니다.

## 현재 공개 범위

**이 저장소는 제작 소스와 한국어 수정 그림을 제공하는 저장소입니다. 일반 사용자가 원본에 적용하는 설치 패치 릴리스는 아직 없습니다.** `Code → Download ZIP`만으로 게임이나 통합판이 설치되지는 않습니다. 게임 전체, 음성·음원·완성 영상과 실행 바이너리는 포함하지 않습니다.

| 폴더 | 내용 |
|---|---|
| `requiem/` | 레퀴엠 제작 도구와 번역 자료 |
| `encore-symphony/` | 앙코르·심포니 제작 도구와 번역 자료 |
| `encore-symphony/collection/` | 공통 메뉴와 통합 감상실 실행기 소스 |
| `assets-ko/` | 실제 한국어판에서 추출한 변경 그림 |
| `review-2026-11/` | 2026년 11월 교정 작업 자료 |

작업 도구에는 제작 당시의 로컬 경로가 남아 있습니다. 실행 전 입력·출력 경로를 자신의 환경에 맞춰 확인해야 합니다. 번역 자료별 제작 주체는 각 기록을 따르며, 서로 다른 시기의 자료를 모두 한 모델의 번역으로 표시하지 않습니다.

## 통합판에서 할 수 있는 일

- 공통 메인에서 작품을 골라 시작하거나 작품별 저장 목록을 열기
- 작품별로 세이브와 진행 상황 보관
- 통합 CG·음악·영상 감상실, 작품별 회상 및 앙코르 에피소드 선택
- CG 휠 확대·축소, 드래그 이동, 화면 맞춤
- 미설치 작품의 문을 흑백과 **미설치** 표시로 구분하고 선택 차단

현재 통합판은 실행 파일 옆 `Games/Requiem`, `Games/Encore`, `Games/Symphony`를 확인합니다. 다른 위치의 설치 게임을 자동 검색하거나 경로를 등록하는 설치 마법사는 아직 없습니다. 자세한 구조와 실행 조건은 [통합판 안내](encore-symphony/collection/README.md)를 참고하세요.
