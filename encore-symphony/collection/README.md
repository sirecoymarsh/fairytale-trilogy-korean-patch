# 통합판 동작과 현재 배포 범위

통합판은 세 게임의 기존 엔진을 실행하는 공통 메뉴입니다. 게임 데이터를 하나의 엔진으로 합치지 않습니다.

```text
페어리테일 통합판.exe
페어리테일 통합판.exe.config
Games/
  Requiem/   # 레퀴엠 실행 파일, scr.xfl, 나머지 게임 데이터와 save/
  Encore/    # 앙코르 실행 파일, scr.xfl, 나머지 게임 데이터와 save/
  Symphony/  # 심포니 실행 파일, scr.xfl, 나머지 게임 데이터와 save/
Entries/     # 작품별 진입 스크립트
Library/     # 공통 화면, 전체 카탈로그, 감상실 자료
Library/cinema/ # 새 제작기의 감상실 MP4
Cinema/      # 이전 통합판에서 사용한 MPEG 영상 경로
Support/     # WebView2 SDK 파일과 타이틀 참조 그림
User/        # 이 통합판의 WebView2 프로필
```

## 작품 실행과 세이브

`시작`은 작품의 첫 장면, `계속`은 원작의 저장 목록, 회상·환경 설정·앙코르 에피소드 선택은 각 원작 화면으로 연결됩니다. 시작 위치를 바꿀 때 현재 `scr.xfl`의 `0000.gsc`만 교체하므로 나머지 시나리오를 이전 복사본으로 되돌리지 않습니다. 게임 프로세스의 작업 폴더는 해당 작품 폴더로 지정합니다. 작품을 종료하면 공통 화면으로 돌아옵니다.

각 작품의 세이브는 `Games/<작품>/save`에 따로 기록됩니다. 다른 곳의 설치본 세이브와 실시간으로 동기화하지 않습니다.

## 일부 작품만 있을 때

해당 하위 폴더의 게임 EXE와 `scr.xfl`이 존재하는지 확인합니다. 없는 작품은 흑백 문에 `미설치`를 표시하고 시작·계속·설정 선택을 막습니다. 감상실에서는 설치된 작품만 목록에 포함합니다. 세 작품 모두 없어도 공통 메뉴와 미설치 안내가 표시됩니다.

실행기의 판정은 기본 파일의 존재 확인입니다. 제작기는 구성 전에 원본과 한국어 파일의 크기·SHA256을 확인합니다. 일부 작품만 선택하면 `Library/catalog.json`의 미선택 작품은 빈 목록으로 작성합니다.

## 제작과 실행 조건

- 통합 실행기: Windows x64, .NET Framework 4.8, Microsoft Edge WebView2 Runtime
- 각 게임: 기존 Windows x86 엔진
- 새 제작기의 감상실 영상: 로컬 원본에서 MP4를 생성하여 WebView2로 재생합니다. 게임 내부 MPEG는 그대로 둡니다. 이전 통합판의 MP4가 없는 영상은 기존 WPF 경로를 사용하며, 이 경로는 WMP 없는 환경에서 `0x88980507` 실패 이력이 있습니다.
- [제작기 사용 방법](BUILDER_README.md): 설치 폴더 선택, 작품별 세이브 가져오기, 별도 출력 폴더 구성. 내장 Python과 기존 변환 도구를 사용하며 제작자의 고정 드라이브 경로가 필요하지 않습니다.
- 서명되지 않은 도구를 차단하는 Smart App Control 환경에서 제작 실패를 확인했습니다. 해당 보안 정책의 적용 환경은 현재 호환성 제한이며 차단을 우회하지 않습니다.

## 2026-11-26 변경

미설치 상태를 작품별로 보고하고 흑백·미설치 표시를 추가했습니다. 세이브 디렉터리가 없어도 상태 조회를 계속하며, 짧거나 읽을 수 없는 세이브 하나가 전체 작품의 상태 전송을 막지 않도록 오류를 작품별로 분리했습니다. 폴더 선택 제작기와 감상실 MP4 경로를 추가했으며 게임 번역과 실행 엔진은 기존 완성본을 재사용합니다.

구현은 기존 C#/WebView2 실행기를 사용합니다. 구조 참고: [Playnite 게임 실행 설정](https://api.playnite.link/docs/manual/library/games/gameActions.html), 미디어 조건: [Microsoft WPF Multimedia Overview](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/graphics-multimedia/multimedia-overview).
