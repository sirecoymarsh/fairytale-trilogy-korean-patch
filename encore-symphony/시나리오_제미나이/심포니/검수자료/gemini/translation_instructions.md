# 원고 읽기
장면 머리의 S1001와 줄 번호 1을 합치면 검수 ID S1001-00001입니다. 두 열은 번호·무표기 원문, 세 열은 번호·화자·원문입니다. 가운데 +는 이어쓰기이며 뒤의 이름은 원래 화자입니다. 가운데 선택문·보기1·보기2 등은 선택지입니다. [선택1]·[선택2]·[합류 뒤]·[공통]은 다음 표시나 장면까지 적용됩니다. 무표기는 지문·독백·인용일 수 있습니다. 이어쓰기는 앞 발화 또는 지문 칸의 연속입니다. 화자 표시만으로 청자가 정해지지는 않습니다. 동석자가 여러 명이면 누구에게 한 말인지 앞뒤 답변에서 확인하세요. 합창·불명 화자·별칭은 원작이 공개하는 범위를 따르세요.
장면은 원본 시나리오 파일의 수록 순서입니다. 선택1과 선택2는 같은 선택문의 대안 전개입니다. 합류 뒤에는 선택에 따른 내부 조건이 남아 있을 수 있습니다. 같은 장면 앞뒤가 잘린 번역 파일에는 참고 행이 따로 있습니다. 참고 행과 레퀴엠의 R로 시작하는 ID는 답에 번역하지 마세요.

# 원본 형식
ID마다 원래 표시 칸 하나를 유지하세요. 이어지는 문장은 함께 해석하고 원래 ID 수에 맞춰 나누세요. 원문 ^n(강제 줄바꿈), ^m, ^cr 등 캐럿 제어는 종류·개수·순서를 그대로 두고 한국어의 대응 위치에 배치하세요. ^n을 JSON 개행이나 실제 줄바꿈으로 바꾸지 마세요. 루비 |표기[읽기]는 표기와 실제 읽기를 모두 해석하세요. 통상적인 발음 안내 루비는 한국어에서 자연스럽게 생략할 수 있습니다. 다른 명칭, 외래어 발음, 이중 의미나 말장난을 전달하는 루비는 두 층을 살려 |한국어표기[한국어읽기]로 반환하고 애매하면 issue에 남기세요. 숫자, 기호가 가진 의미와 선택지의 대응을 보존하세요. 대상 ID나 원문을 나누거나 합치지 마세요.

# 번역 응답
한 번에 요청한 묶음의 대상 ID만 원래 순서대로 반환하세요. JSON 형식은 {"packet":"S001","scenes":{"S1001":[[1,"번역문"]]},"issues":[]}입니다. 각 장면에 [숫자, 한국어] 쌍을 원래 순서로 넣으세요. issues와 해석표의 근거는 장면을 포함한 전체 검수 ID로 적으세요. issues에는 {"id":"대상 ID","reason":"확인이 필요한 이유","needed":"판정에 필요한 증거"}를 쓰세요. 확인 사항이 없으면 빈 배열을 쓰세요. 번역 본문에는 작업 메모를 끼워 넣지 마세요. 완료한 묶음에서 새로 확인한 호칭이나 용어는 필요한 경우 voice_updates 배열에 원문 ID와 함께 남겨 다음 묶음에 재사용하세요. 처음 해석표에서 잠정으로 둔 판정도 원문 근거가 생기면 바꿀 수 있습니다.
