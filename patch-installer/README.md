# 작품별 한국어 패치

[릴리스](https://github.com/sirecoymarsh/fairytale-trilogy-korean-patch/releases/tag/patches-preview-2026.11.26)에서 해당 작품의 `Fairytale_…_Korean_Patch_20261126_preview.zip`을 받습니다. 원본 게임에 덮어쓰지 않고 별도의 독립 한국어판을 만듭니다.

1. ZIP 전체를 풀고 `한국어 패치 적용.exe`를 실행합니다.
2. 해당 작품의 원래 일본어 이름 EXE가 들어 있는 지원 설치 폴더를 고릅니다.
3. 기존 기록이 필요할 때만 **세이브 가져오기**를 선택합니다.
4. 원본·패치 폴더와 겹치지 않는 새 빈 폴더를 지정합니다.
5. 완료 후 완성 폴더의 게임 EXE를 실행합니다.

Windows 10/11 64비트와 .NET Framework 4.8 이상이 필요합니다. Python과 xdelta3는 동봉되어 있으며 개별 패치에는 WebView2가 필요하지 않습니다. 다른 파일 버전은 `manifest.json`의 해시 검증에서 중단됩니다. 게임용 MPG는 기존 검증된 파일로 유지하고 홍보용 MP4로 교체하지 않습니다.

`build_standalone.py`는 기존 브릿지 제작기의 파일 검증·차분 적용·선택 세이브 복사 방식을 재사용합니다. `prepare_releases.py`는 기존 검증된 제작기와 개발자의 입력 목록을 받아 세 작품의 패치 키트를 분리합니다. 입력 목록은 로컬 원본과 한국어판 경로를 포함하므로 공개 배포 대상이 아닙니다. 게임 원본은 GitHub에서 제공하지 않습니다.

새 설치기는 심포니 실제 GUI 적용과 생성된 한국어 첫 장면·정상 종료, 출력 폴더 겹침 거부를 확인했습니다. 레퀴엠·앙코르의 동일 패치 데이터 적용·실행 결과는 기존 검증을 재사용하며 새 GUI에서 각각 전 과정을 다시 수행한 것은 아닙니다. [전체 검증 범위](../releases/verification-20261126.json)를 확인하세요.
