## 페어리테일 한국어 패치와 통합판 제작기

레퀴엠·앙코르·심포니 개별 패치, 기존 브릿지와 단일 엔진 **이야기 모음** 제작기를 한 릴리스에 정리했습니다. 이용하려는 작품의 지원 설치본이 필요하며, 원본 게임 전체와 개인 세이브는 포함하지 않습니다.

**브릿지**는 1~3개 작품의 게임 실행을 공통 메뉴로 연결하며, 없는 작품은 흑백으로 표시합니다. **이야기 모음**은 세 작품 모두가 필요하고 한 게임 엔진에서 시나리오를 실행합니다. 두 제작기 모두 작품별 세이브 가져오기를 선택할 수 있습니다.

ZIP을 모두 풀고 패치 적용/제작기 EXE에서 설치 폴더와 새 빈 출력 폴더를 선택하세요. 완성 폴더는 통째로 옮길 수 있습니다. `Source code` ZIP은 실행용 패키지가 아닙니다.

### 함께 제공하는 자료

- 레퀴엠 한국어 오프닝 MP4: **45.34 MB**
- 앙코르 한국어 오프닝 MP4: **45.14 MB**
- 게시판용 한국어 홍보문, `SHA256SUMS.txt`, `verification-20261126.json`

홍보 영상은 각각 50 MB 미만입니다. 게임용 MPG는 기존 재생 규격을 유지하며 이 홍보 MP4로 교체하지 않습니다.

### 확인한 범위

- 기존 원본→한국어 파일 84개 검증과 세 작품 기본 실행 기록을 재사용했습니다.
- 새 개별 설치기는 심포니 GUI 적용·출력 20개 파일·한국어 첫 장면·정상 종료, 겹치는 출력 경로 거부를 추가 확인했습니다. 레퀴엠·앙코르의 새 GUI 전체 적용은 다시 수행하지 않았으며 동일한 기존 차분/게임 검증 결과를 재사용했습니다.
- 브릿지는 세 작품 제작·시작·복귀, 선택 세이브, 다른 드라이브로 이동, 설치 조합 8가지와 감상실 32개 경로를 확인했습니다.
- 이야기 모음은 한 게임 프로세스에서 세 작품 첫 장면·복귀, 앙코르 저장·불러오기, 설정·취소 후 복귀, 선택 세이브, 이동 후 실행·종료를 확인했습니다. 시나리오·메뉴 GSC 428개를 보존합니다.
- ZIP CRC·내부 해시와 배포 파일 목록을 확인했으며 새 ZIP 4개는 Defender 검사에서 위협이 발견되지 않았습니다. 기존 브릿지 ZIP은 동일 해시의 통과 결과를 재사용했습니다.

### 남은 검증과 환경 제한

**전체 분기·엔딩 완주, 모든 게임 내 영상의 연속 전체 재생, 다른 PC에서의 전체 제작·실행은 미완료입니다.** 기본 작동 확인을 전체 완주 검증으로 표시하지 않습니다.

Windows 10/11 64비트와 .NET Framework 4.8 이상이 필요합니다. 두 통합판에는 WebView2도 필요하며 설치 파일을 동봉했습니다. 코드 서명이 없는 미리보기이고, 기존 Windows Sandbox 검사에서는 Smart App Control이 xdelta3를 차단했습니다. 이 정책 환경은 현재 호환성 제한이며 보안 설정 변경이나 차단 우회를 요구하지 않습니다.
