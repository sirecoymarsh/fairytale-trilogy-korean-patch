# 레퀴엠 전체 콘텐츠 개방 — 미리보기 4

레퀴엠 개별판·브릿지·단일 엔진 이야기 모음에 빠져 있던 감상 기록 기능을 추가했습니다.

환경 설정 → **감상 기록**에서 다음 기능을 사용합니다.
- **모든 콘텐츠 해방:** CG 63묶음/219차분, 회상229개, 음악·영상·특전 개방.
- **해방 취소:** 직접 얻은 기록으로 복귀.
- **초기화:** 감상·읽음 기록 초기화. 진행·저장 슬롯·설정은 보존.
- **초기화 되돌리기:** 백업 복원과 이후 새 기록 병합.

기본값은 개방 꺼짐입니다. 통합판에서는 레퀴엠 설정에서 변경한 뒤 성 메인으로 돌아오면 공통 감상실에도 반영됩니다. 기존 시스템 문구·글꼴·시나리오 진행 수정도 포함합니다. 두 제작기는 지원 원본과 앞선 레퀴엠 한국어판에서 새 폴더로 업데이트할 수 있습니다. 세이브 가져오기는 선택입니다.

이번 반복 검사에서 통합판의 회상·설정 복귀 오류도 발견해 수정했습니다. 새로 선택한 진입점과 엔진의 저장된 스크립트 ID·복귀 위치가 달랐던 문제입니다. 최종 DLL은 레퀴엠→앙코르→심포니→레퀴엠 네 차례의 회상 닫기·설정 확인창 취소·메인 복귀를 모두 통과했습니다. 최종 네 차례 중 실패0회이며 전체 게임의 오류율을 뜻하지 않습니다.

숨김·음소거 사본에서 개별판 네 버튼, 개방 취소, 초기화·복원 전후 동일성, 슬롯·설정 보존과 공통 감상실의 개방/취소/초기화/복원을 확인했습니다. 재실행 후 개방 유지, 회상9페이지 및 이전 미개방 장면 진입을 확인했습니다. 동봉 설치기로 개별판45파일과 단일 엔진 제작85입력을 확인했고, 새 델타는 지원 입력별로 실제 복원하여 목표 해시와 일치했습니다. 공개 빌드 소스도 EXE·시나리오·설정 아카이브를 바이트 단위로 재현했습니다. 브릿지의 변경되지 않은 감상실 변환과 이전 전체 설치 검증은 재사용했습니다.

ZIP CRC·SHA-256과 최종 패키지 Defender 검사(탐지0)를 확인했습니다. 상세 범위와 산출물 해시는 `verification-content-options-20261128.json`에 있습니다.

기존 주요 루트 검증은 이전 기록을 재사용했습니다. 이번 변경판의 모든 분기·229회상 전체 재생, 다른 PC 전체 제작·실행은 미검증입니다. 앞서 관찰된 음성 전환 대기 문제와 진행 중인 아르곤 전체 재번역은 이번 수정으로 완료되지 않았습니다. 코드 서명이 없는 미리보기입니다.
