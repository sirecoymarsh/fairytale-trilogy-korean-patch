# 레퀴엠 2026.11.28 실행 오류 수정판

레퀴엠 일부 루트에서 대사 본문과 이어쓰기의 합산 줄수가 화면 한도를 넘어 진행이 막히던 문제를 수정한 **미리보기 패치**입니다.

- 5개 시나리오 파일의 10개 문자열을 정리했습니다. 명령·분기·음성·세이브 형식은 그대로이며, 대부분 줄바꿈 조정과 의미를 보존한 짧은 문장 축약 2곳입니다.
- 지원 일본어 원본과 **2026.11.26 한국어판**을 입력으로 사용할 수 있습니다. 기존 한국어판 폴더를 선택하고, 진행을 이어가려면 **세이브 가져오기**를 선택해 새 빈 폴더에 만드세요.
- 레퀴엠 주요 **12/12 엔딩과 타이틀 복귀**를 확인했습니다. 공통 구간·변경되지 않은 분기 결과는 재사용하고, 수정한 오류 구간은 실제 엔진에서 다시 확인했습니다. 배포 차분 결과는 검증본의 SHA-256과 일치합니다.
- 동봉 Python을 사용한 이전 한국어판 업데이트는 정상 종료했고 출력 44개 파일의 해시를 확인했습니다. 설치 화면과 실행 파일은 검증된 기존 것을 재사용했습니다.

### 발견한 실패와 남은 제한

서로 다른 대사 넘침 오류 2곳을 실제로 재현했고, 같은 구조의 후보까지 수정했습니다. 음성 전환 대기는 1회 관찰됐으며 동일 구간 재실행과 엔딩 진행은 보조 조작 없이 통과했지만, 원인 확정과 EXE 수정은 아직 끝나지 않았습니다.

**12/12는 목표 엔딩 도달률이며 오류 발생률 0%라는 뜻은 아닙니다.** 저장 불러오기·분기 재사용·원인 조사 중의 개입을 포함한 시험이어서 실행 시도 수를 동일 조건으로 셀 수 없습니다. 게임 실행 실패율은 임의의 백분율로 제시하지 않습니다. 모든 선택지·회상·게임 내 영상·다른 PC까지 검증한 정식판도 아닙니다.

이번 파일은 **레퀴엠 개별판용**입니다. 앙코르·심포니·브릿지·이야기 모음은 [2026.11.26 릴리스](https://github.com/sirecoymarsh/fairytale-trilogy-korean-patch/releases/tag/patches-preview-2026.11.26)를 이용하세요. 이전 통합 제작기에는 이번 수정이 자동으로 반영되지 않으며, 새 `scr.xfl` 해시도 아직 지원하지 않습니다.

전체 아르곤 재번역은 별도로 진행 중이며 이번 배포에는 포함하지 않았습니다. 원본 게임 전체와 개인 세이브는 포함하지 않습니다. 기존 Smart App Control의 서명되지 않은 xdelta 차단 제한은 유지됩니다.
