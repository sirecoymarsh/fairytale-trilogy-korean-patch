# 페어리테일 레퀴엠 한국어 번역 스타일 가이드 (초안)

## 기본 원칙

- 원문 의미와 장면 분위기를 우선하고, 한국어 문장은 자연스럽게 다듬는다.
- 화자별 말투와 호칭은 장면 문맥을 확인한 뒤 일관되게 유지한다.
- 인명 표기는 `glossary.json`을 따른다. 전체 번역 전에 표기를 확정한다.
- 대사창 폭을 고려해 지나치게 긴 문장은 자연스러운 호흡 단위로 나눈다.

## 엔진 마크업

- `^n`, `^m`, `^d2`, `^d3`, `^s2` 등 캐럿 제어 코드는 원문의 종류·개수·순서를 보존한다.
- 루비는 `|표기[읽기]` 형식이다. 한국어에서 불필요하면 본문만 자연스럽게 번역하되, 루비를 남길 때는 괄호 구조를 정확히 보존한다.
- opcode `0x79`의 디렉터리/조회 키는 번역하지 않는다.
- opcode `0x0F` 문자열은 런타임 표시 여부가 확인될 때까지 번역 대상에서 제외한다.

## 검수

- 모든 목표 문자열은 CP949로 인코딩 가능해야 한다.
- 파일별 빌드 후 비대상 슬롯, 명령 구간, 후행 구간이 원본과 동일한지 확인한다.
- 정적 검증 뒤 실제 게임에서 글꼴, 줄바꿈, 선택지, 저장/불러오기, 설정 화면을 확인한다.
